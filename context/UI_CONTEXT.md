# UI Context

## Theme

Dark and light mode. The design language is a technical
workspace with layered surfaces, and vivid accent or primary colors for interactive elements.


## Component Library

shadcn/ui on top of Tailwind. Components live
in components/ui/. Use the CLI to add new components
rather than writing from scratch.

## Icons

Phosphor-icons/react. Stroke-based icons only. Sizes:
h-4 w-4 for inline, h-5 w-5 for buttons.
