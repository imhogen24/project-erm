# Engineering Design Process — ERM Tool Structure

> For reference only.

| Tool ID | Name | ERM Inclusion | Remark |
|---|---|---|---|
| D5.0 | Project Traceability & Sources | NOT PART | Reference layer. Accessible globally; not an active ERM tool |
| P0 | Admin & Resource Traceability | NOT PART | Entry point. Captures team, tools, and environment setup |
| P1.0 | Master Requirements Register | PART | Central repository of all approved requirements |
| P2.0 | Master Capacity & Execution Plan | PART | PM-controlled. Defines allocation, timelines, and execution plan |
| P1.1–P1.7b | Requirement Development | NOT PART | Requirement building happens offline; only final outputs go into P1.0 |
| P1.8 | Requirement Review | NOT PART | Reviews occur per tool; not needed as standalone ERM tool |
| Pr1–Pr8 | Specification Shaping | NOT PART | Internal engineering cognition; not system-tracked |
| P2.1–P2.8 | Design Planning Tools | NOT PART | Collapsed into P2.0 |
| Pr2.1 | ERM Gantt Chart (Auto-Generated) | PART | Generated from P2.0. Not manually edited |
| Pr2.2a–Pr2.02f | EPDM Tracking Tools | NOT PART | Replaced by ERM-native tracking |
| P3.1 | Transformation Process Definition | PART | Defines system-level transformation logic |
| P3.1a | Technical Process Description | PART | Textual definition of transformation logic |
| P3.1b | Technical Process Diagram | PART | Visual diagram (file upload required) |
| P3.2 | TS Function Structure Definition | PART | Defines system functional breakdown |
| P3.2a | TS Function Structure (Duplicate) | NOT PART | Redundant; removed to avoid duplication |
| P3.2b | Evoked Function Structure Definition | PART | Defines functional behaviors and properties |
| P3.3 | TS Function Structure Representation | PART | Visual FuStr diagrams (file upload required) |
| P4.1A | Morphological Matrix | PART | Core idea grid; text or image per cell |
| P4.1B | Function-Based Morphological Matrix | PART | Function-driven variation of matrix |
| P4.1C | Concept Synthesis | PART | Combination of selected concepts |
| P4.1D | Evaluated Concept Synthesis | PART | Refined/filtered synthesis output |
| P4.2A | Topological Principles Definition | PART | Concept-level structural logic; file upload required |
| P4.2B | Topological Representation (Icons) | PART | Visual symbolic representation |
| P4.2C | Organ Design from Functional Requirements | PART | Mapping function → physical structure; multi-file support |
| P4.2D | Final Organ Structure Definition | PART | Finalized system architecture; multi-file support |
| P5.1A | Consolidated Requirement List | PART | Structured requirement list for construction stage |
| P5.1B | Validated Requirement Set | PART | Final validated requirements for execution |
| P5.2 | Construction Concept Development | PART | Initial construction ideas; multi-file support |
| P5.3 | Construction Elaboration | PART | Detailed engineering development |
| P5.3.1 | Preliminary Layout Representation | PART | Layout drawings and structural arrangement |
| P5.4 | Construction Group Definition | PART | Grouping of system components |
| P5.4.1 | Construction Structure Definition | PART | Final structural definition for CAD |
| P6 | Master Model Decomposition | PART | Breaks system into parts for detailing; feeds Phase 6 |
