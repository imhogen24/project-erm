# Sheet colour codes

Each tool comes with a screenshot of its sheet. The cell colours decide each field's type in `defineTool`.

| Colour | Meaning | How to build it |
|---|---|---|
| Dark grey | Section title | The field's `section`, using the sheet's wording. |
| Green | Label or column header | The field's label or column label, using the sheet's wording. |
| Green with a red border | Header of a table that grows | Users can add rows, the same way existing tables in the app work. The SN column numbers itself and the user never types it. |
| Yellow | Editable default | Starts pre-filled, and the user can change it. The starting value usually comes from the system or is already on the sheet, and a struck-through note may say where. **If the source is not clear, ask the developer.** Never guess it. |
| Pink | Fixed default | Pre-filled exactly as written on the sheet. The user cannot edit it. Any text in `[square brackets]` is filled in by the system, for example `[Client Name]` or `[Total GHS]`. |
| Purple | Select | A choice from fixed options. If the sheet names the options (for example Active / Archived), use them. **Otherwise ask the developer for the options.** |
| Orange | PDF preview | Read-only reference, always shown as a PDF preview. Either a stored PDF, or another tool's record rendered as a PDF. Nothing is typed here. Where a stored PDF comes from is the developer's decision for that tool. Build it as `type: "pdfPreview"` with `source: { tool: "D1.15" }`, or `source: { file: "company-sla.pdf", title: "Company SLA" }` for a PDF added to `documents/`. |
| Cyan | Empty text input | The user types into it. It starts empty. Use a short text field or a long text area to suit the content. |
| Magenta | File upload | The user uploads a file. |

## Other marks

- **Struck-through text** is a note for the agent to read. It never appears on the screen.

## Before you build

- List every yellow cell and every purple cell that has no options, and ask the developer about them before writing code.
- When a colour on the sheet does not match this table, ask. Do not choose a field type yourself.
