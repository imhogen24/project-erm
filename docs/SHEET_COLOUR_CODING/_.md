# Colour-coding a workbook

How an AI agent colours the uncoloured tool tabs of a workbook in Google Drive, so every tool has a colour-coded sheet to build from. What each colour means is in `docs/SHEET_COLOUR_CODES/_.md`. Read that first.

## What you need

- The Google Drive and Google Sheets connectors switched on for your agent.
- The **AGENT_USE** folder in Drive:
  - `SHARED`: the general framework and the training guides (TRG-xx). Read them for context.
  - `WORKBOOK_N`: the workbook to colour, plus that workbook's policy document.
- `uv`, which runs the reading scripts with `openpyxl`.

## Rules

- Edit the real workbook file. Never create a copy to test on.
- Colour only tool tabs (`D2.1`, `2.9`, `T3.D4.8a` …). Leave the index tab (`.i`) and the master database tab alone, and skip any tab that has been deleted.
- Leave signature cells uncoloured.
- Never change cell text. Only fill colours and the header box change.
- An already-coloured tab is the reference. Match it; don't recolour it.

## Steps

1. **Read for context.** Read the workbook's policy document in `WORKBOOK_N` and its training guide in `SHARED` (for example TRG-04 for Workbook 4). They say what each tool does, which earlier tool feeds it, and who fills it in.
2. **Export the sheet.** Download the workbook as `.xlsx` with the Drive connector (`download_file_content`) into your scratch folder.
3. **Find the work.** Run:
   ```
   uv run --with openpyxl python scripts/sheets/tabs.py <file.xlsx>
   ```
   A tab with `{}` has no colours yet.
4. **Read each tab.** Run:
   ```
   uv run --with openpyxl python scripts/sheets/dump.py <file.xlsx> D4.1 D4.2
   uv run --with openpyxl python scripts/sheets/merges.py <file.xlsx> "D4.1|15,26"
   ```
   `dump.py` prints every cell with its text. `merges.py` shows merged ranges. A merged cell takes its colour from its top-left cell, so paint that cell only.
5. **Choose a colour for each cell.** Use the table in `docs/SHEET_COLOUR_CODES/_.md` and the rules below. Write the plan as JSON, one entry per tab, keyed by the tab's `sheetId` (from `get_spreadsheet`):
   ```json
   {
     "180695637": {
       "_tab": "D4.1",
       "GREY": "A9 A14",
       "GREEN": "A10 A11",
       "HEADER": {"15": "A B H N R"},
       "PINK": "A16:A19",
       "YELLOW": "B16:B19",
       "CYAN": "H16:H19",
       "PURPLE": "R16:R19",
       "ORANGE": "U10"
     }
   }
   ```
   Cells are separated by spaces, and `B16:N19` means every cell in that rectangle. `HEADER` lists the header cells of a table users can add rows to.
6. **Build the requests.** Run:
   ```
   python3 scripts/sheets/build_requests.py plan.json requests.json
   ```
   It stops if a cell is given two colours. For each header row it paints the cells green and draws the header box: a red medium outline with black medium dividers across columns A–X.
7. **Send them.** Pass each tab's request list to `update_spreadsheet` as `requests`. Send a few tabs per call.
8. **Check them.** Read a few cells back with `get_spreadsheet` (`includeGridData`, field `effectiveFormat.backgroundColor`), including at least one header row and one table body.
9. **Report back.** Give the sheet link, the tabs you coloured, the tabs you skipped and why, and every judgement call to confirm. List each call as: tab, cell, chosen colour, reason.

## Choosing colours

| What the cell holds | Colour |
|---|---|
| A numbered section title (`1.0 …`) | Grey |
| A label, or a column header in a fixed table | Green |
| A column header of a table with an SN column, where users add rows | Green, listed under `HEADER` |
| An SN cell, or text the user must not change (fixed clauses, instructions, a script) | Pink |
| A value the system works out (totals, working days, team size, `[Client Name]`) | Pink |
| A value copied from an earlier tool that the user can still change | Yellow |
| A choice: Yes/No, a status, a person picked from the team, a select whose options are written in the cell | Purple |
| A link to or reference of another tool's record, or a stored document | Orange |
| Free text, a comment, a date or time the user types | Cyan |
| "Upload", "attach", a link to a file the user provides | Magenta |

When a cell could be two colours, choose the one the training guide supports and add it to the report as a judgement call. Never leave a field uncoloured because you're unsure.

## Colour values

| Colour | Hex |
|---|---|
| Grey | `CCCCCC` |
| Green | `B6D7A8` |
| Yellow | `FFE599` |
| Pink | `EA9999` |
| Purple | `B4A7D6` |
| Orange | `F9CB9C` |
| Cyan | `A2C4C9` |
| Magenta | `D5A6BD` |

These are kept in `scripts/sheets/colours.py`.
