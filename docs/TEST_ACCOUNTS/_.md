- You see: On Dev: D1.14 Tier 1 · 1 Fill in (LE): 1.0 Base technical labor cost, one row to start: type the module, Estimated Days and Daily Rate, and Total Labor Cost fills in as you type, with the Base Labor Subtotal under the table. 2.0 Direct project costs: Add row for each item, Quantity times Unit Cost, Direct Cost Subtotal. 3.0: the three layers locked in place, each with an Applied Rate (%): Project Management & QC is worked out on the base labor, Administrative Overhead and Sustainability / Risk Margin on the labor and direct costs; Total Project Value under them. 4.0 starts with one row per deliverable of D1.13's included scope: type each Fully Loaded Alloc.
