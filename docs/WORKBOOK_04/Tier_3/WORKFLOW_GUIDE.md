# Workbook 04 (Team Assignment & Capacity Planning) — Tier 3 Workflow Guide

Unlocked once D2.14's advance payment clears. Tier 3 replaces the entire Tier 1 chain (D4.1–D4.8) with a single fast-track tool — no formal capacity review and no kick-off meeting, since these jobs are typically under 5 days.

---

### T3.D4.8a — T3 Drafting Assignment & Baseline

- **Why:** one sign-off that covers assignment, access, and technical baseline for a small drafting job, replacing the full 8-step Tier 1 process.
- **App does:** provides the assignment, access-checklist, and technical-baseline tables in a single form.
- **Staff does:** assigns the drafter directly (skillset, hours, start/target dates) — no formal capacity review; confirms client source data, the CAD folder, and the software license are ready; sets the drafting standard, tolerance class, and deliverable format; PM and the assigned engineer both sign, acknowledging no further briefing is needed.
- **Client does:** nothing directly — their source data from T3.D1.3a feeds this.
- **Unlocks:** engineering execution.

```
T3.D4.8a → unlocks engineering execution
```

## Hard stops

None specific to this tool — it's a single sign-off, not a multi-step chain.
